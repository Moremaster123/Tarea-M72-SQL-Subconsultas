# Tarea M72: subconsultas, CTE y tablas temporales

Tarea de SQL Server de la profesión Full Stack Python de EBAC, hecha sobre la base de datos de ejemplo [AdventureWorks2022](https://learn.microsoft.com/es-es/sql/samples/adventureworks-install-configure).

## Tecnologías

- SQL Server (T-SQL)

## Consultas

| # | Tema | Resultado |
|---|---|---|
| 1 | Subconsulta con IN | Productos que se han vendido, ordenados por nombre |
| 2 | JOIN de cuatro tablas | Empleados con su departamento actual |
| 3 | CTE (WITH) | El mismo resultado del ejercicio 2 usando un CTE |
| 4 | Tablas temporales | Tabla local `#ProductosOrdenados` y global `##ProductosOrdenados` |
| 5 | YEAR() | Órdenes del año 2011 |
| 6 | SUBSTRING() | Números de orden y de compra sin los dos primeros caracteres |

## Cómo ejecutarlo

1. Restaura AdventureWorks2022 en SQL Server.
2. Abre el archivo `.sql` en SQL Server Management Studio o en Azure Data Studio.
3. Ejecuta el script completo o cada consulta por separado.
